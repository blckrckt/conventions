# Рекомендации по работе с задачами

- При работе с задачами следует разбивать ее на три этапа и между каждым этапом делать перерывы:
  1. Функциональность
  2. Рефакторинг
  3. Стилистика

## Тестирование

- Проверять верстку на различных браузерах (для проверки на винде браузера Safari используй [Browserling](https://www.browserling.com/) или [BrowserStack](https://www.browserstack.com)).
